# Security policy

Please do not publish credentials, personal information, client configuration, private prompts,
or proprietary agent instructions in issues or pull requests.

For a suspected vulnerability, email `info@alijabbary.com` with:

- the affected version;
- minimal reproduction steps using synthetic data;
- expected impact;
- any safe mitigation already identified.

The scanner reads repository-local Markdown, TOML, and JSON. It does not execute discovered
commands or connect to declared servers. Run it only on projects and files you are authorized to
inspect.
